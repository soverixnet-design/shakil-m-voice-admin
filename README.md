## ✨ Features & Capabilities

- 🔐 **Super Admin Security Gate**:
  - Secure Google OAuth sign-in restricted to Owner email (`yfastvpn@gmail.com`).
  - Emergency Master Security PIN (`admin123`) for instant authentication on any device.
- 👥 **Real-time User Management**:
  - Search by Name or ID with live filters (All, Admins, SVIP members, Banned users).
  - Add new users with custom balances, SVIP ranks, and badges.
  - 1-Click Ban / Unban and Role promotion/demotion.
- 💰 **Recharge & Coin Approval System**:
  - Review all pending user coin purchase requests in real-time.
  - 1-Click Approve (instantly credits coin balances to users) or Reject.
- ⚡ **1-Click Owner Master Booster**:
  - Automatically grants +10,000,000 Coins, +50,000 Diamonds, and SVIP 3 to the Owner account.
  - Unlocks all special animations and exclusive VIP badges.
- 🎙️ **Voice Rooms Oversight**:
  - Monitor all live 8, 12, and 20-seat rooms, participants, and categories.
  - Delete or close violating rooms instantly.
- 📢 **Live System Notice & Banner Ticker**:
  - Broadcast scrolling banner alerts directly across all user rooms in real-time.
